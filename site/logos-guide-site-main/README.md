# Путеводитель по колледжу

Интерактивная карта двух этажей, поиск помещений, маршруты по коридорам и небольшие игры.

## Запуск

```bash
npm ci
npm run dev
```

Проверки: `npm test`, `npm run lint`, `npm run build`.

## Приветственное окно и QR-код приложения

При первом заходе сайт показывает диалог «Сайт в разработке» с просьбой сообщать о багах команде проекта. Тумблер «Больше не показывать» сохраняет выбор в `localStorage` (ключ `logos-welcome-hidden`); чтобы окно снова появилось, удалите этот ключ в браузере.

> **QR-код — заглушка.** `public/android-app-qr.png` сейчас ведёт на репозиторий проекта. Когда появится настоящая ссылка на скачивание Android-приложения (APK / магазин), замените этот файл QR-кодом на неё — код сайта трогать не нужно (картинка подключается в `src/components/WelcomeDialog.jsx`).

## День открытых дверей

Режим мероприятия показывает пять площадок (аудитории 138, 148, 114, 113 и 228): на карте они отмечены звёздами, в справочнике — плашкой. Клик по такой аудитории открывает модалку с описанием, ведущими и кнопкой маршрута.

**Выключить в моменте:** тумблер «День открытых дверей» в шапке сайта — состояние сохраняется в браузере. **Выключить по умолчанию в сборке:** переменная окружения `VITE_OPEN_DAY=false` при `npm run build`. Список площадок и описания — в `src/openDay.js`.

## Карта и маршруты

Исходные планы: `map1lower.svg` и `map2lower.svg`. Координаты кликабельных помещений, дверей и проходов находятся в `src/map-geometry.js`. Алгоритм строит путь вдоль главного коридора и западного крыла; для перехода между этажами выбирает лифт или ближайшую из трёх лестниц (`src/map-routing.js`). Если план меняется, обновите SVG, геометрию и тесты вместе. Маршрут не учитывает временно закрытые помещения и не гарантирует доступность проходов.

Ручная отметка ставится **в любой точке помещения или коридора**, сохраняется только в браузере пользователя и может стать началом маршрута. Её можно удалить на карте.

**GPS не определяет этаж и не привязан к схеме автоматически.** Чтобы появилась приблизительная метка, на выбранном этаже включите GPS и отметьте две известные точки, находясь в них. Первая точка показывается как неподвижный ориентир, после второй рассчитываются масштаб и поворот плана. Координаты этих двух точек сохраняются только в локальном хранилище браузера; другие полученные GPS-координаты никуда не передаются. Внутри здания погрешность может превышать размеры кабинета: при сомнении используйте ручную отметку. Функция требует HTTPS и разрешения на геолокацию.
