# Публикация в Google Play и App Store

---

# Часть 1. Google Play (Android)

## 1.1. Подготовка

1. Аккаунт [Google Play Console](https://play.google.com/console) ($25 единоразово).
2. Production-сборка в формате **AAB**:

```bash
cd logos-guide
eas build --platform android --profile production
```

3. Готовые материалы:
   * **Иконка** 512 × 512 PNG — `assets/images/logo.png`;
   * **Feature graphic** 1024 × 500 PNG (баннер для страницы приложения);
   * **Скриншоты**: минимум 2 для телефона (1080 × 1920 или 1080 × 2340);
     можно сделать скриншоты приложения в Expo Go / на устройстве;
   * **Краткое** (до 80 символов) и **полное** описание на русском и английском;
   * **Политика конфиденциальности** — нужна, если приложение запрашивает геолокацию
     (в нашем случае да): разместите страницу (GitHub Pages, Google Sites) и укажите ссылку.

## 1.2. Создание приложения в консоли

1. Play Console → **Все приложения → Создать приложение**.
2. Заполните:
   * Название: **ЛОГОС: Путеводитель**
   * Язык по умолчанию: русский
   * Тип: приложение / Бесплатно
3. Пройдите обязательные шаги слева:
   * **Конфиденциальность → Политика конфиденциальности** — укажите URL.
   * **Доступ к приложению** — если функционал ограничен, отметьте (наш — публичный).
   * **Рекламный идентификатор** — заявите, что рекламы нет.
   * **Целевая аудитория** — 13+ (или 18+).
   * **Новостное приложение / Данные** — ответьте, что собираются ли данные:
     мы не передаём данные на сервер, геолокация обрабатывается локально.
   * **Вопросы безопасности данных** — заполните форму: данные не собираются.

## 1.3. Загрузка сборки

1. **Создание → Настройка → Базовая комплектация** (Production) → **Создать релиз**.
2. Вариант А — загрузите `.aab` вручную (**Загрузить**).
   Вариант Б — из терминала:

```bash
eas submit --platform android --latest
```

(EAS попросит ключ сервисного аккаунта Google — инструкция появится в консоли.)

## 1.4. Внутреннее тестирование (перед публикацией)

1. **Тестирование → Внутреннее тестирование → Создать релиз** → загрузите тот же AAB.
2. Добавьте тестировщиков (списки email) и отправьте ссылку-приглашение.
3. Тестировщики устанавливают приложение из Play Store по ссылке.
4. Нужно **минимум 12 тестировщиков**, согласившихся тестировать непрерывно 14 дней,
   прежде чем можно публиковать для личных аккаунтов разработчиков (требование Google 2023+).

## 1.5. Публикация

1. **Публикация → Страницы приложения** — заполните описание, скриншоты, иконку.
2. **Основной список → Создать релиз** → выберите AAB → **Далее**.
3. Укажите **Примечания к выпуску** («Первый выпуск»).
4. **Сохранить → Отправить на проверку**.
5. Проверка Google занимает от нескольких часов до 7 дней.

# Часть 2. App Store (iOS)

## 2.1. Подготовка

1. Аккаунт Apple Developer Program ($99/год).
2. Production-сборка:

```bash
cd logos-guide
eas build --platform ios --profile production
```

3. Материалы:
   * Иконка 1024 × 1024 PNG (без альфа-канала);
   * Скриншоты: 6,7" (1290 × 2796) и 6,5" (1242 × 2688) — минимум 3 на каждый размер;
   * Описание, ключевые слова (до 100 символов), категория **Образование**;
   * URL политики конфиденциальности;
   * Контакт для поддержки.

## 2.2. Создание записи в App Store Connect

1. Откройте [App Store Connect](https://appstoreconnect.apple.com) → **Мои приложения → +**.
2. Заполните:
   * Платформа: iOS
   * Название: **ЛОГОС: Путеводитель**
   * Основной язык: русский
   * Bundle ID: `ru.logos.guide`
   * SKU: `logos-guide-001`
3. В разделе **1.0 Готово к отправке** заполните описание, скриншоты, возрастной рейтинг 4+.

## 2.3. Загрузка сборки

Вариант А — через EAS:

```bash
eas submit --platform ios --latest
```

EAS попросит Apple ID (нужен пароль приложения — App-Specific Password),
создаст сертификаты и загрузит сборку.

Вариант Б — через Xcode:
1. Откройте `.xcarchive` в Organizer → **Distribute App → App Store Connect → Upload**.

## 2.4. TestFlight (обязательный этап)

1. В App Store Connect → вкладка **TestFlight** → дождитесь обработки сборки (10–30 минут).
2. Добавьте **Внутренних тестировщиков** (до 100 человек, доступ сразу).
3. Для внешних тестировщиков (до 10 000) нужен бета-ревью Apple.
4. Тестировщики устанавливают **TestFlight** из App Store и принимают приглашение.

## 2.5. Отправка на ревью

1. В разделе сборки нажмите **Готово к отправке → Отправить на рассмотрение**.
2. Ответьте на вопросы:
   * **Экспортное соответствие** — приложение не использует нестандартное шифрование;
   * **Содержание рекламы** — нет;
   * **Идентификатор рекламы (IDFA)** — не используется.
3. Ревью Apple: обычно 24–48 часов.

## 2.6. Частые причины отказа

| Причина | Как избежать |
|---|---|
| «Ваше приложение запрашивает геолокацию без объяснения» | В `app.json` прописаны `NSLocationWhenInUseUsageDescription` — убедитесь, что текст осмысленный |
| «Нужна политика конфиденциальности» | Укажите URL в App Store Connect |
| Пустые экраны / краш при запуске | Проверьте сборку через TestFlight до отправки |
| Скриншоты не соответствуют | Делайте скриншоты с реального устройства |

# Часть 3. Обновления приложения

1. Увеличьте версию:
   * `app.json` → `expo.version` (например `1.1.0`) и `expo.android.versionCode`,
     `expo.ios.buildNumber`;
   * или используйте `autoIncrement: true` в `eas.json` (профиль `production`) —
     EAS увеличит номера сборок автоматически.
2. Соберите заново:

```bash
eas build --platform android --profile production
eas build --platform ios --profile production
```

3. Отправьте в магазины (см. выше).
