# Логос — офлайн-навигатор колледжа

«Логос» — нативное Android-приложение для навигации по зданию АНО ПО «Технический колледж „Логос“». Репозиторий содержит приложение, локальные данные двух этажей и инструменты проверки геометрии.

## Назначение

Приложение объединяет планы этажей, каталог помещений и маршрутизацию внутри здания. Каталог и построение маршрута работают с локальными данными; внешняя картографическая подложка, включая 2GIS, и WebView в Android-приложении не используются.

## Статус версии на 2026-11-16

Целевая версия по текущему плану разработки — **`1.0.1-release`**. Это планируемый релиз: APK, Git-тег и опубликованный GitHub Release с этой версией не обнаружены. Не скачивайте для этого перехода другой локальный или более старый APK.

## Планируемый переход на `1.0.1-release`

> Чтобы установить новую `1.0.1-release`, нужно сначала удалить установленную старую версию приложения, затем установить новый APK.

Это инструкция **для будущего перехода после публикации официального APK**, не предложение скачать APK сейчас.

1. **Сначала сохраните доступные данные.** Если в установленной старой версии доступен экспорт, откройте раздел «Избранное», выберите экспорт JSON и сохраните файл вне приложения — например, в общей папке «Документы» или «Загрузки». В исходниках опубликованного тега `release` такой экспорт предусмотрен; фактический APK не запускался на устройстве. JSON включает категории/папки, избранное, историю и сохранённые маршруты, но не настройки. Перед удалением убедитесь, что файл виден в файловом менеджере и хранится не в закрытом каталоге приложения.
2. **Удалите старое приложение.** Удаление может стереть локальные избранное, историю, маршруты, настройки и другие данные приложения. Не полагайтесь на Android Backup: восстановление для этого перехода не проверялось и не гарантируется.
3. **После фактической публикации** установите только официальный APK `1.0.1-release`. Сейчас ссылки на такой APK нет.
4. **Восстановите данные**, только если совместимость импортёра конкретного опубликованного `1.0.1` подтверждена: в «Избранном» выберите импорт JSON и укажите сохранённый файл. Код импортёра в текущем `origin/main` принимает backup schema 1–2, включая schema 2 старого исходника, но это не runtime-проверка будущего APK `1.0.1`.

Установку старой версии поверх новой как обычное обновление и автообновление из `1.0.0-opendoors` не обещаем. Точная техническая причина требования удалить старую версию (например, несовпадение сертификата) **не подтверждена**: APK `1.0.1` ещё отсутствует, а подпись опубликованного старого APK не сравнивалась с целевым APK.

## Android-приложение

Нативный клиент написан на Kotlin с Jetpack Compose и Material 3. Архитектура построена вокруг MVVM, репозиториев, `StateFlow`, Room и Preferences DataStore. Цвета интерфейса: синий `#2F5FE8`, фон `#F3F6FB`, тёмный акцент `#8AA8FF`; используется шрифт Onest.

Основные возможности:

- векторная карта двух этажей с перемещением, масштабированием и локализованными подписями;
- русский и английский интерфейс, поиск помещений по названиям, номерам и алиасам;
- локальная прокладка маршрутов с выбором лестничного или лифтового перехода;
- ручная установка стартового положения и необязательное GPS-позиционирование; GPS сам не определяет этаж;
- компас, сопровождение маршрута, голосовые подсказки и вибрация прибытия — в зависимости от настроек и системных компонентов;
- избранное, пользовательские папки, история и сохранённые маршруты;
- карточки OpenDoors-каталога остаются в исходниках, но отключены (`OPEN_DOORS=false`) в новых Debug- и Release-сборках.

Единый source-based перечень активных, опциональных и отключённых функций, источников и тестового покрытия находится в [каталоге функций](docs/FEATURES.md).

## Сеть и автообновление

Карты, каталог и построение маршрута локальны. Встроенный updater отправляет запрос к публичному GitHub Releases API. В сборках с updater проверка выполняется при запуске не чаще раза в 24 часа; ручная проверка доступна в About. APK не скачивается и не устанавливается незаметно: пользователь нажимает «Скачать», затем подтверждает установку в Android Package Installer. Клиент сравнивает числовые компоненты `versionName`, а не `versionCode`; детали, ошибки текущего latest-тега и ограничения перехода описаны в [инструкции по сборке](docs/BUILD_APK_RU.md).

Исходники опубликованного тега `release` с `1.0.0-opendoors` не содержат updater. Поэтому установленная старая версия не может сама обнаружить или скачать `1.0.1-release`; целевой APK придётся установить вручную по шагам выше. Даже конфигурация updater в текущем `main` (`1.1.0-release`) считает `1.0.1-release` более старой по своим числовым `versionName` и не подтверждает этот переход.

## Карты, данные и сборка

Исходные SVG-планы находятся в `maps_and_design/floors/`; `tools/generate_kotlin_floor_maps.py` создаёт производное Kotlin `Canvas`/`Path`-представление. Каталог и граф маршрутов поставляются в `app/src/main/assets/rooms.json` и `navigation_graph.json`. Данные помещений и геометрия имеют известные неполевые/неподтверждённые участки; приложение не заменяет указатели и официальные инструкции колледжа.

Параметры Android-вариантов, текущие значения `versionName`/`versionCode`, конфигурация workflow и доступные проверки приведены в [документе сборки](docs/BUILD_APK_RU.md). OpenDoors=false относится к новым сборкам и не изменяет уже опубликованные или отслеживаемые APK.

## Структура

| Путь | Содержание |
|---|---|
| `app/` | Android-приложение, ресурсы, локальная база и тесты |
