# Логос — офлайн-навигатор колледжа

«Логос» — нативное Android-приложение для навигации по зданию АНО ПО «Технический колледж „Логос“». Репозиторий содержит приложение, локальные данные двух этажей и инструменты проверки геометрии.

## Назначение

Проект объединяет планы этажей, каталог помещений и маршрутизацию внутри здания. Android-приложение работает с локальными картами и данными: для каталога и построения маршрута серверное соединение не требуется. Внешняя картографическая подложка, включая 2GIS, в Android-приложении не используется.

## Android-приложение

Нативный клиент написан на Kotlin с Jetpack Compose и Material 3. Архитектура построена вокруг MVVM, репозиториев, `StateFlow`, Room и Preferences DataStore.

Основные возможности:

- векторная карта двух этажей с перемещением и масштабированием и локализованными подписями;
- русский и английский интерфейс с английским fallback для неподдерживаемых системных локалей;
- поиск помещений на русском и английском языках, включая номера и алиасы;
- локальная прокладка маршрутов по геометрии здания с выбором лестничного или лифтового перехода;
- ручная установка положения и необязательное GPS-позиционирование без автоматического определения этажа;
- каталог, избранное, пользовательские папки, история и сохранённые маршруты;
- карточки площадок Дня открытых дверей в release-варианте `1.1.0-release`.

Избранное, пользовательские коллекции, история, маршруты и настройки сохраняются локально. Карты, каталог и маршрутизация работают без сети; разрешение `INTERNET` используется только для проверки публичных релизов GitHub и загрузки APK обновления. GPS-координаты на сервер не отправляются.

Бесплатный канал обновлений использует GitHub Releases. Приложение проверяет наличие версии при запуске не чаще одного раза в сутки, предлагает загрузить подписанный APK и передаёт его системному установщику Android. Установка требует подтверждения пользователя и подписи тем же ключом, что и установленная версия. В `1.0.0-opendoors` клиент обновлений отсутствует, поэтому переход на `1.1.0-release` выполняется вручную один раз; авто-проверка действует для `1.1.0-release` и следующих выпусков.

## Карты и навигационные данные

Исходные векторные планы находятся в `maps_and_design/`, а их копии для проекта — в `app/src/main/assets/floors/`. Скрипт `tools/generate_kotlin_floor_maps.py` преобразует планы в Kotlin `Canvas`/`Path`-представление; SVG не загружаются Android-приложением во время работы.

`navigation_graph.json` описывает этажи, узлы, рёбра, GPS-якоря и закрытые зоны. `rooms.json` содержит каталог, поисковые алиасы, полигоны и состояние маршрутной доступности. Координаты заданы в системе SVG `viewBox`. Часть дверей, коридорных связей и GPS-якорей имеет предварительный статус и не является результатом полной полевой съёмки.

## Сборка и качество

Android-конфигурация использует `minSdk = 24`, `targetSdk = 36`, `compileSdk = 37`, JVM target 17, Android Gradle Plugin 9.3.1, Gradle 9.7.0, Kotlin 2.4.21 и KSP 2.3.12. Идентификатор release — `versionName = "1.1.0-release"`, `versionCode = 4`; итоговое имя APK — `logos-guide-1.1.0-release.apk`.

Проверки проекта включают Android unit tests, сборки Debug/Release, проверку идентичности APK и валидацию связности графа, JSON и геометрии SVG.

## Структура репозитория

| Путь | Содержание |
|---|---|
| `app/` | Android-приложение, ресурсы, локальная база и тесты |
| `app/src/main/assets/` | SVG-планы, каталог помещений и граф навигации |
| `tools/` | генератор векторных карт и проверка геометрических данных |
| `docs/` | описание модели данных, карт и конфигурации сборки |
| `maps_and_design/` | исходные планы и предоставленные графические материалы |
